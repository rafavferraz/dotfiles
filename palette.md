# Color Palette

## Primary Colors

| Role           | Hex       | Usage                        |
|----------------|-----------|------------------------------|
| Yellow/Gold    | `#F0D080` | Folder path, modified (pastel)|
| Green          | `#8DC07C` | Git branch, added/created    |
| Red/Pink       | `#FF6B80` | Warnings, deleted            |
| Blue/Teal      | `#63A1A3` | UI accent, indicator         |
